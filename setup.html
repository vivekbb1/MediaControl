Remote layout — grid order & buttons

Grid order controls section position (Master, Sources, Screen Sharing, Volume presets, etc.). Button order within each grid is separate — reorder, rename, and set an exact columns × rows grid for consistent button placement. Click Save remote layout after changes.

Icons: Each button row has an Icon dropdown. Auto uses the default for that source (e.g. Apple → apple, AirPlay → airplay). Set per-grid Display to Icon only for a clean icon grid. See defaults: Apple, Teams, Browser, Whiteboard, AirPlay, SmartView, Flip, Power, Mute/Unmute, Reboot.
